# Memory — how the coach remembers you

This folder is the coach's continuity. It is the only place the coach agent may
write. It is plain markdown so you can read it, edit it, or delete it at any
time — it is *your* record, not the coach's.

## Files

- **`profile.md`** — your living coaching profile. The coach reads it at the
  start of every session and updates it at the end.

## The contract

**At session start** the coach reads `profile.md` and opens by picking up where
it left off — referencing open loops by name, asking how last session's material
is sitting now. It never starts from zero.

**At session end** the coach updates `profile.md`:
- a dated session note (what came up, what shifted, what's still open)
- the open loops (beliefs / identities in flight, with status)
- patterns noticed over time (five-element lean, recurring themes)
- safety-relevant facts, recorded honestly and gently

## Your control

- **Read it any time.** Nothing here is hidden from you.
- **Edit it any time.** If something is wrong or you want it gone, change it.
- **Delete it any time.** Ask the coach to wipe the file, or delete it
  yourself. A blank profile just means the coach starts fresh.

## What the coach will never put here

- Diagnoses or labels it isn't qualified to make.
- Anything you shared in a moment you'd want kept private — the coach will
  always tell you what it's writing and why.
